 Week 1 — Networking Fundamentals

During Week 1, I focused on understanding basic networking tools and how computers communicate with remote servers.

 Lab 1: cURL — HTTP Requests

Commands practiced:

curl https://example.com -o example.html
curl -I https://example.com

What I learned:

How to send an HTTP GET request from the terminal.

How to download and save HTML content locally.

How to inspect HTTP response headers.

How to interpret HTTP status codes.

 View cURL Documentation

 Lab 2: Ping — Network Connectivity

Command practiced:

ping -c 4 tdmax.com

Results from my original test:

Packets transmitted: 4

Packets received: 4

Packet loss: 0%

Average round-trip time: 53.726 ms

What I learned:

How to test basic network connectivity.

How to interpret packet loss.

How to measure network latency.

Why connectivity testing matters in troubleshooting.

 View Ping Documentation

 Lab 3: Traceroute — Network Routing

Command documented:

traceroute example.com

Concepts explored:

How packets travel across multiple networks.

What network hops represent.

How traceroute helps investigate network paths.

Why some routers do not respond to diagnostic probes.
